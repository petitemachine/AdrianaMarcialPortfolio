TDAH / ADHD Project

Work in progress

Objective: To design a flexible routine system that helps neurodivergent children move through everyday activities with greater independence, predictability and less overwhelm.

This case study is currently being researched and documented. More details will be added as the project develops.

UX / UI project plan

  1. Define the user problem and intended audience.
  2. Research user needs, barriers and existing solutions.
  3. Create the information architecture and key user flow.
  4. Develop wireframes and an interactive prototype.
  5. Run a usability test with representative participants.
  6. Iterate the interface and document the findings.
